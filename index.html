02 — Sobre mí

El código
también se lee

Un endpoint no termina cuando responde 200. Termina cuando otra persona puede entenderlo, probarlo y cambiarlo sin miedo.

Soy Eudy Joel Reyes, backend developer. Trabajo con Node.js, TypeScript y PostgreSQL construyendo APIs que priorizan la claridad sobre la improvisación.

Mi enfoque está en las decisiones que sostienen un sistema cuando crece: contratos de API explícitos, validación en los bordes, seguridad desde el diseño, tests que documentan el comportamiento y una estructura por capas que no obliga a adivinar dónde vive cada cosa.

Fuera del trabajo mantengo proyectos propios y pruebas técnicas para seguir practicando: desde un acortador de URLs con autenticación completa hasta automatizaciones con IA. Me gusta entender el problema antes de escribir la primera línea.
